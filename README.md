# Async-fifo-verilog
Parameterized asynchronous FIFO in Verilog with Gray code pointers
## Status
In progress

## Features
- Parameterized data width and depth
- Gray-code read/write pointers
- 2-flop synchronizers for clock domain crossing
- Full and empty flag generation

## Planned
- Self-checking testbench
- SystemVerilog assertions and coverage
- Synthesis report (Vivado)

## Tools
Verilog HDL, Vivado / Icarus Verilog, GTKWave
